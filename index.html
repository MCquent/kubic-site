Controls

  • Litematica (.litematic), WorldEdit / Sponge (.schem) and structure block (.nbt) files.
  • The game's own block models and textures, from its latest version — boats, minecarts and item frames included.
  • Layer by layer: the cut falls exactly between two layers, to rebuild a machine floor by floor.
  • Free flight like in the game — WASD or ZQSD, the game's own mouse sensitivity, a ×4 zoom you hold down.
  • Aim at a block to read its name and state; hide it to see what is behind.
  • Smooth on builds of 150,000 blocks: one buffer per layer, and hidden faces are never drawn.
  • Your schematics in one library, a folder per game version, shared with your instances.

Server manager

Everything a hosting panel gives you — locally, with no subscription.

A dozen tabs per server. What used to take an SFTP client, a text editor and a command window now fits in a single app.

Set up in three steps

Pick the type, the version, the build. The jar is downloaded, the EULA accepted, the folders created, the port and RAM set. Already have a server folder or a modpack? Import it as is.

Live console

Coloured output, filter by text and level, command history on the arrow keys, quick commands, log export.

server.properties, explained

Some 50 keys documented and grouped, with typed controls — checkboxes, sliders, lists. Raw editing of the file is still one click away.

File manager

Full browsing, text / JSON / YAML / TOML editing, drag and drop, upload and download, zip and unzip, recursive search, image preview.

Plugins & mods from Modrinth

A catalogue filtered by the server's loader and version, one-click install with dependencies resolved, enable, disable, local jars welcome.

Players, ops and bans

Operators with their level, whitelist, player and IP bans. Through the console while the server runs, straight in the JSON files otherwise, UUIDs resolved with Mojang.

Worlds

Activate, rename, duplicate, reset, delete, import a .zip. The test world and the serious one can finally live side by side.

World map

A top-down map of your world, rendered straight from its region files — no plugin, nothing to install on the server.

Backups

Full ZIP archives, worlds only or configuration only, one-click restore and automatic rotation of the oldest ones.

Scheduled tasks

Restart, backup, stop, start, a command or an announcement — at a regular interval, every day or every week.

Network

One port per server, local and public addresses, automatic port opening on your router (UPnP), port test and server ping. More below.

Performance and safety

Minimum and maximum RAM, JDK choice, JVM flag presets (Aikar's, basic or your own), auto-restart after a crash. Closing Kubic sends every server a clean stop.

Play together

Your friends join with a name, not an IP address.

The Network tab opens the port on your router by itself, checks that it works, and can give your server an address that is easy to share — yourname.kubicmc.com — which follows your IP when it changes.

  • Automatic port opening on your router (UPnP), server by server — and a step-by-step guide when the router says no.
  • One port per server, chosen at creation and editable at any time. Up to two servers can run at once.
  • Local and public addresses, port test from the outside, server ping.
  • The custom address is optional. Claiming one publishes your public IP in DNS, like any domain name — release it in one click and it is gone.

Click a player to open their profile: inventory, hotbar, armour, offhand, ender chest, health, hunger, experience, game mode, dimension, coordinates, spawn point — and their statistics: play time, deaths, mobs killed, blocks mined.

  • Textures extracted from the client you already have, or downloaded from Mojang and checked with SHA-1.

Launcher

And it launches the game, too.

An instance is a version with its own memory, Java, resolution and account. By default it uses your existing .minecraft: your worlds, mods and options stay where they are. A separate game folder is one checkbox away.

  • Vanilla, Fabric, Forge, NeoForge, Quilt, OptiFine and LiteLoader.
  • Modpack import: Modrinth .mrpack, CurseForge, or a plain .zip of mods. Duplicate mods are flagged, and an instance's mods export as a .zip.
  • Per-instance worlds and backups, duplication, a filterable game log, screenshots and schematics (.schem, .nbt) sorted by version.
  • Client jar, libraries, natives and assets downloaded in parallel and checked with SHA-1 — nothing is downloaded twice.
  • Offline account for your local servers, Microsoft account for everything else.
  • The Kubic menu: a cleaner title screen, installed in one click from an instance's settings (Fabric, 1.20.5 and later).

AI companions, if you want them.

Optional and off by default: a companion joins your local server and plays alongside you — it moves, gathers, fights and chats. Run it on a local model, free and entirely on your PC, or on Anthropic's Claude with your own API key, billed to your account.

Your Microsoft password never goes through Kubic.

Signing in opens Microsoft's real page, in its own window, through the authorization code + PKCE flow. Kubic only receives a single-use code, exchanged for a token that is stored on your PC and refreshed automatically. No home-made e-mail / password form: third-party software that collects Microsoft credentials is the very definition of phishing. The offline account asks for nothing at all.

Java

The right Java, installed for you.

Compatibility is a range, not a minimum: a Java that is too recent breaks things as surely as one that is too old. Kubic detects the JDKs you have, picks the one that fits, warns you when none does — and installs the right one in a click.

Built-in installation

Eclipse Temurin JDKs install from the settings: no Windows installer, no PATH changed, no registry touched. Each archive is checked against its SHA-256 hash before extraction.

Automatic detection

JAVA_HOME, PATH, Program Files, Adoptium, Microsoft, Zulu, Corretto, BellSoft and the official launcher's runtime are all inspected. A runtime installed by Kubic takes precedence over a system JDK of the same version.

    Questions

    What people ask us.

    Is Kubic free?

    Yes, entirely, under the MIT licence. No account to create, no paid feature, no ads.

    Do I need to own Minecraft?

    To play on public servers in online-mode, yes: you need a Microsoft account that owns the game. To host and join your own local servers, the offline account is enough.

    Windows shows a warning when I install it.

    The installer is not signed with a commercial certificate, and SmartScreen warns about every publisher it does not know yet. Click More info, then Run anyway. To be sure the file is the one we published, compare its SHA-256 hash with the one shown in the download section.

    Is any of my data sent anywhere?

    No telemetry, no usage statistics, no crash reports. Your servers, worlds, backups and accounts stay on your PC. Kubic only goes online to download what you ask for (game versions, server jars, mods, Java) and to sign you in with Microsoft. Two optional features go further: a custom address sends its name, your port and a public key to Kubic's service and publishes your IP in DNS; an AI companion on Claude sends its exchanges to Anthropic. Everything is detailed in the privacy notice.

    Can my friends join my server?

    Yes. The Network tab opens the port on your router automatically when it supports UPnP, and walks you through port forwarding when it does not. It also gives you an address to share — your public IP, or an optional yourname.kubicmc.com. Kubic does not host anything for you: the server runs on your PC.

    How many servers can run at the same time?

    Two at once, each on its own port. You can create as many as you like.

    What if a server is running when I close the app?

    Each server receives a clean stop and the time to write its chunks before the app closes. Nothing is killed abruptly.

    Can I bring my existing worlds and servers?

    Yes. Import an existing server takes a server folder as it is, downloading nothing; the Worlds tab imports a .zip; and modpacks import into a server or an instance.

    Which languages does Kubic speak?

    English, French, Spanish, German, Italian and Portuguese — switch at any time in the settings.
