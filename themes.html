Themes

Give Kubic your colours

Four skins come with Kubic, more themes are here to download, and your own takes two files. Extensions follow the colours of the theme you choose.

  1. 1Download a theme below: a single .zip file.
  2. 2In Kubic, Settings → Appearance → Load a theme, then pick the file.
  3. 3It applies at once. None brings back the original look.

To download

Everything a theme needs fits in its .zip — colours, and sometimes a background image: nothing reaches outside. Install one, and Kubic takes on its look at once.

Built into Kubic

Nothing to download: Settings → Appearance → Visual theme. They work in dark and light mode.

NoneThe original look, monochrome.
InkInk black, magenta accent, a cyan-to-pink edge.
EmberWarm browns, amber accent.
BlueprintSlate green-grey, teal accent.
IndigoNight blue, periwinkle accent, an aurora edge.

Make your own

A theme is a .zip with two files. Change only the colours you want: the others keep their value.

theme.json

{
  "id": "my-theme",
  "nom": "My theme",
  "auteur": "you",
  "version": "1.0"
}

theme.css

:root,
:root[data-theme="light"],
:root[data-theme="dark"] {
  --bg:        #0b0b0f;   /* window background */
  --panel:     #131319;   /* cards */
  --panel-2:   #17171f;
  --line:      #23232c;   /* borders */
  --txt:       #e8e8ef;   /* main text */
  --txt-2:     #b4b4c2;
  --txt-3:     #8a8a99;   /* small text */
  --accent:    #7c5cff;   /* buttons, selection */
  --on-accent: #ffffff;   /* text on the accent */
}

Images

Put them in the archive and call them by a relative path, for example url(images/background.png). Accepted: png, jpg, webp, gif, woff and woff2.

Nothing from outside

Remote addresses are removed when the theme is installed: a theme never contacts anyone. Archives are limited to 200 files and 32 MB.

Tweak and reload

Loading an archive whose theme.json has the same id replaces the installed version: change a colour, load it again, see the result.

Dark and light

Define the three selectors above to impose your colours in both modes, or only :root[data-theme="light"] to style light mode alone. If a theme goes wrong, None brings everything back.

Share it

Send the .zip to your friends, or write to contact@kubicmc.com to have it listed here — with images you have the right to share.
